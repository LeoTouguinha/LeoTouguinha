🧭 Como penso Dados

Dados não geram valor. Decisões geram valor.
A arquitetura existe para transformar dados confiáveis em decisões confiáveis.

Essa é a premissa do D³A — Decision-Driven Data Architecture, um framework que venho desenvolvendo para conectar arquitetura de dados, governança, qualidade, IA e consumo de dados àquilo que realmente importa: decisões e resultados de negócio.

Dados → Governança → Qualidade → IA & Analytics → Decisão → Resultado

O objetivo não é construir apenas pipelines, dashboards ou modelos.

É construir uma base capaz de responder:

“Podemos confiar na decisão que estamos tomando?”

🔬 Projeto em destaque
🚗 Previsão de Sinistros de Auto

Projeto de Machine Learning aplicado ao mercado de seguros, desenvolvido para prever a probabilidade de ocorrência de sinistros e apoiar decisões relacionadas à gestão de risco.

O projeto percorre uma jornada completa de dados:

Dados históricos
       ↓
Exploração & Data Quality
       ↓
Feature Engineering
       ↓
Tratamento de desbalanceamento
       ↓
Modelagem preditiva
       ↓
Otimização de hiperparâmetros
       ↓
Avaliação do modelo
       ↓
Interpretação dos resultados
       ↓
Decisão de negócio

A solução explora modelos de classificação e técnicas de avaliação orientadas ao problema de negócio, considerando métricas como Precision, Recall, F1-Score e PR-AUC, além da análise do trade-off entre identificação de riscos e falsos positivos.

Mais do que buscar o melhor score, o projeto considera um princípio fundamental:

Um modelo preditivo só gera valor quando suas previsões podem ser transformadas em decisões melhores.

Por isso, o projeto também documenta as escolhas metodológicas, limitações e diferenças de performance entre os modelos — reforçando a importância de transparência, validação e confiabilidade em aplicações de Machine Learning no setor de seguros.
